# Vendored AsciiPanel

The sources in this package (and the `*.png` font sheets in
`src/main/resources/`) are vendored, unmodified, from
[trystan/AsciiPanel](https://github.com/trystan/AsciiPanel) at commit
`372dfbae98`, under the **MIT License** (see `LICENSE.md` here).

AsciiPanel is not published to Maven Central, and this project no longer
uses jitpack; vendoring the four classes keeps the build self-contained.
