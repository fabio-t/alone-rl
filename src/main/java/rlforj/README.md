# Vendored rlforj-alt

The sources in this package are vendored from
[fabio-t/rlforj-alt](https://github.com/fabio-t/rlforj-alt) at tag
`0.3.0`, under the **BSD 3-Clause License** (see `LICENSE` here),
unmodified except for dropping the `rlforj.examples` package.

rlforj-alt is not published to Maven Central, and this project no longer
uses jitpack; vendoring keeps the build self-contained.
